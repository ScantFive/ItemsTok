Экспорт объявлений с Циан

  1. Перетащите эту кнопку на панель закладок браузера:

    ItemsTok: сохранить

    Не видно панели закладок — нажмите Ctrl+Shift+B (на Mac — ⌘+Shift+B). Можно и вручную: создайте закладку и вставьте в поле адреса код из поля ниже.

  2. Откройте поиск аренды на Циан: Москва, Петербург. Если Циан покажет капчу — пройдите её как обычно.
  3. Нажмите закладку «ItemsTok: сохранить» — скачается файл itemstok-….json.
  4. Хотите больше объявлений — откройте страницы 2, 3… внизу списка и нажмите закладку на каждой.
  5. В папке проекта выполните npm run import-data — объявления попадут на сайт.
