# ItemsTok

Лента объявлений об аренде квартир с [Циан](https://www.cian.ru) в стиле Instagram.
TypeScript + Vite, без фреймворков.

Сайт: **https://scantfive.github.io/ItemsTok/**

- лента карточек с каруселью фото, бесконечная прокрутка;
- ♥ или двойной тап по фото — добавить в избранное;
- выбор города — Москва или Санкт-Петербург (запоминается);
- избранное хранится локально в браузере (`localStorage`), вместе с данными объявления.

## Что делать: пошагово

### Шаг 1. Один раз: включить GitHub Pages

1. Репозиторий на GitHub → **Settings → Pages**.
2. **Source: Deploy from a branch**, ветка **`gh-pages`**, папка **`/ (root)`** → **Save**.

Ветку `gh-pages` создаёт и обновляет workflow «Deploy to GitHub Pages» при каждом пуше.
Не выбирайте ветку с исходниками (`main` и т. п.) — там несобранный TypeScript, и страница будет белой.

### Шаг 2. Один раз: подготовить компьютер

Объявления сохраняются **из вашего браузера**: вы открываете поиск на Циан как обычно, а закладка
сохраняет то, что уже показано на странице. Программные запросы Циан закрывает капчей, поэтому
автоматической выгрузки нет.

1. Установите [Node.js](https://nodejs.org) версии 20 или новее и [Git](https://git-scm.com/downloads).
   Проверка в терминале (на Windows — PowerShell):
   ```bash
   node -v   # v20.x или выше
   git --version
   ```
2. Скачайте проект и установите зависимости:
   ```bash
   git clone https://github.com/ScantFive/ItemsTok.git
   cd ItemsTok
   git checkout claude/adoring-edison-1b6dw8   # или main, когда ветку вольют
   npm install
   ```
3. Убедитесь, что `git push` работает (при первом пуше Git попросит войти в GitHub —
   через браузер или [personal access token](https://github.com/settings/tokens)).
4. Поставьте закладку: откройте **https://scantfive.github.io/ItemsTok/export.html** и перетащите
   кнопку **«ItemsTok: сохранить»** на панель закладок браузера
   (не видно панели — Ctrl+Shift+B, на Mac ⌘+Shift+B).

### Шаг 3. Сохранить объявления в браузере

Для **Москвы** и для **Петербурга**:

1. Откройте поиск аренды на Циан:
   [Москва](https://www.cian.ru/cat.php?deal_type=rent&engine_version=2&offer_type=flat&region=1&type=4),
   [Петербург](https://www.cian.ru/cat.php?deal_type=rent&engine_version=2&offer_type=flat&region=2&type=4).
   Фильтры (цена, комнаты, метро) можно настроить как угодно — сохранится то, что в списке.
2. Нажмите закладку **«ItemsTok: сохранить»** — скачается файл `itemstok-<город>-p<страница>-….json`
   в папку «Загрузки».
3. Хотите больше объявлений — перейдите на страницу 2, 3… внизу списка и нажмите закладку на каждой.

Если Циан покажет капчу — пройдите её как обычно и нажмите закладку ещё раз.

### Шаг 4. Отправить на сайт

В папке проекта:

```bash
npm run import-data
```

Команда находит файлы `itemstok-*.json` в папке «Загрузки», объединяет страницы каждого города
(убирая повторы), записывает `public/data/1.json` (Москва) и `public/data/2.json` (Петербург),
делает коммит и `git push`. Через 1–2 минуты обновите сайт: над лентой будет
**«Объявления Циан, выгрузка от …»**. Ход сборки — во вкладке **Actions → Deploy to GitHub Pages**.

Берутся только файлы последнего сеанса (сохранённые в пределах 3 часов от самого свежего),
так что старые загрузки не смешаются с новыми. Если город не сохраняли — у него остаются прежние данные.

- Файлы лежат в другой папке: `npm run import-data -- путь/к/папке` (или пути к файлам).
- Без отправки на GitHub: `npm run import-data -- --no-push` (потом `git push` вручную).

### Обновлять объявления

```bash
git pull
```
затем шаги 3 и 4.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| Белая страница | Проверьте шаг 1: в Pages должна быть выбрана ветка `gh-pages`. |
| «Приложение не запустилось…» | То же, что выше. |
| «…показаны демо-объявления» | Для этого города ещё нет выгрузки — выполните шаги 3–4. |
| Закладка: «откройте поиск аренды квартир на cian.ru» | Закладку нажали не на сайте Циан. |
| Закладка: «на этой странице не нашлось объявлений» | Откройте список объявлений (поиск), а не карточку квартиры или главную. Если список открыт, а сообщение есть — Циан изменил страницу, напишите об этом. |
| Ничего не скачалось после нажатия | Браузер мог спросить разрешение на скачивание — разрешите. |
| `Не найдено файлов itemstok-*.json` | Файлы сохранились не в «Загрузки» — укажите папку: `npm run import-data -- путь`. |
| `Данные не изменились — отправлять нечего` | Всё в порядке, новых объявлений нет. |
| Ошибка при `git push` (`Authentication failed`, `403`) | Войдите в GitHub в Git (шаг 2.3) и повторите `git push`. |
| Объявления на сайте не обновились | Подождите 2 минуты и обновите страницу; проверьте, что последний запуск в Actions зелёный. |

## Для разработки

```bash
npm run dev          # http://localhost:5173
npm test             # юнит-тесты
npm run import-data  # импорт файлов закладки в public/data + коммит + пуш
npm run build        # сборка в dist/
```

Порядок источников в приложении: выгрузка из `public/data` → живой запрос (только если при сборке
задан `VITE_CIAN_API`, см. ниже) → демо-данные для городов без выгрузки.

## Прокси для Циан (Cloudflare Worker, необязательно)

> Сейчас Циан часто отвечает этому прокси капчей, поэтому основной способ — экспорт из браузера (шаги 3–4).
> Без переменной `CIAN_API_URL` сайт к прокси не обращается.

`worker/index.ts` — узкий прокси: `GET /search?region=1&page=1` → `{ offers: [...] }`
(и `GET /debug` — что Циан отвечает прокси). Он ходит только в поиск аренды Циан, кэширует ответ
на 10 минут и отвечает браузеру только с сайтов из `ALLOWED_ORIGINS` (`worker/wrangler.toml`).

Развёртывание — workflow «Deploy CIAN proxy (Cloudflare Worker)»; нужны секреты репозитория
`CLOUDFLARE_API_TOKEN` (шаблон токена «Edit Cloudflare Workers») и `CLOUDFLARE_ACCOUNT_ID`
(строка после `dash.cloudflare.com/` в адресе кабинета). Чтобы сайт им пользовался, добавьте
переменную репозитория `CIAN_API_URL` = адрес воркера и перезапустите «Deploy to GitHub Pages».
